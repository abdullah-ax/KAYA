# Daily check-in

Runs when the founder opens the app on a new day. Proactive, not pushy. Follow `house_voice.md`.

1. Show "Where we left off" in 3 lines from `run_state.json`.
2. Ask the 3 questions in `templates/daily_checkin.md`, one at a time.
3. Pick one lesson from `kb/lessons/daily_lessons.md` for the founder's weakest area today. Link to the real source. Give one action due today.
4. If an open question has waited 2+ days, ask about it once.

No streaks, no guilt, no countdowns. Save the answers to `notes.md` with the date.
