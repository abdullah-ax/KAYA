## How to help

- Open an issue for bugs or ideas. Pull requests need passing tests (`python3 -m pytest -q tests` and `cd web && npx vitest run`).
- New agent prompts go in `prompts/`, new knowledge notes in `kb/` with a source link for every claim.
- The full guide is in [CONTRIBUTING.md](CONTRIBUTING.md).
